# Everything in one table

This page lists every page in the repository, grouped in a few different ways.
It is here for the times when you do not yet know what you are looking for and
would rather browse than search.

If you do know what you want, searching for a tag is usually faster. The
[tag list](TAGS.md) explains which tags exist.

This table is maintained by hand, which means somebody has to remember to
update it. When you add a page, please add a row. It takes about ten seconds.

*Everything below is example content, invented for this prototype.*

## One honest note about this page

Because this table is maintained by hand, it will slowly go out of date if
nobody keeps it up. Search never goes out of date, because it reads the files
directly.

Both are worth having. This table is for browsing when you do not know what
you want. Search is for the times when you do.
