# Layout options with Figma Make

> I tried using Figma Make to generate layout variations from an existing
> page, and it did not work. This page exists so that you do not spend your
> credits finding that out for yourself.

**Written by:** [@kuidja] · **Last checked:** August 2026

---

## Why this is worth your time

Only because it will save you the attempt. You can skip straight to the
section below on where it does not work.

---

## What I tried

1. I opened an existing page design in Figma.
2. I asked Figma Make for three layout variations that kept the same content.

---

## Where it does not work

It rebuilt the components from scratch instead of reusing the ones that were
already in the file. The results looked plausible enough in a screenshot, but
they were unusable in practice, because the instances were detached and the
spacing did not match anything in Vanilla.

It also used up a large share of a month's credits in a single afternoon,
which is worth knowing before you start.

If what you want is a few layout options, sketching three of them yourself is
genuinely faster than repairing what this gives you.
