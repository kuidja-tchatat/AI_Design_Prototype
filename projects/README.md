# Projects

This folder holds every page in the repository. There are no sub-folders
inside it.

That makes adding a page very simple, because there is only one place to put
things and no category to choose. Finding a page works through tags and search
instead.

Here are the three ways to find what you need:

* **Search.** Type a tag into the box at the top of the page that says
  "Search this repository". GitHub searches inside every file.
* **Browse the grouped view.** The [index](../INDEX.md) lists everything in
  one table, sorted by job and by tool.
* **Look up what a tag means.** The [tag list](../TAGS.md) explains every tag
  and the values it can take.

Files whose names begin with `EXAMPLE-` are sample pages. They exist to show
the shape a page should take, and the content in them is invented.

To add a page of your own, copy the [template](../_TEMPLATE.md), save it in
this folder, and fill in the tags at the top. The
[contributing guide](../CONTRIBUTING.md) explains each step.
